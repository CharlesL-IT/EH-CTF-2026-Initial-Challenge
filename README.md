# Dockerized Linux Escape CTF Challenge

## Overview

This project is a custom containerized Capture The Flag challenge designed to simulate a restricted Linux “cell escape” environment. Players interact with a remote Linux container and must analyze the filesystem, discover hidden artifacts, and interact with custom binaries to retrieve the final flag.

The challenge was developed as part of a cybersecurity coursework project focused on Linux security concepts, containerization, and adversarial thinking.

---

## Objectives

The challenge was designed to demonstrate:

- Linux filesystem enumeration
- Access control and file permission concepts
- Docker container deployment
- Challenge-based cybersecurity learning
- Restricted shell environments
- Custom binary interaction
- CTF challenge design and testing
